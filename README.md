# Lillero interaktivt kort

Seneste kort med 16 telte, faciliteter og infobokse.

## Til Squarespace

Brug [den færdige kodeblok](squarespace/lillero-kodeblok.html). Kopiér hele filens indhold ind i én HTML Code Block på Squarespace.

[Se den korte vejledning](squarespace/README.md) til indsættelse, links og grafik.

## Standalone-version

`index.html` indeholder det oprindelige kort, og `public/images/` indeholder grafikken. Kør eventuelt `python3 -m http.server 8000` fra projektmappen og åbn http://localhost:8000.

Den eksisterende liveversion: https://lillero-interactive-map.fremskriv.chatgpt.site/

GitHub og Squarespace opdateres separat. Den nye Squarespace-kodeblok er ikke automatisk installeret på Lilleros hjemmeside.
